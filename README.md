## 🎪 Sobre o JuKids

O **JuKids** é um sistema web desenvolvido para facilitar a gestão de uma empresa de locação de brinquedos para festas e eventos.

A ideia nasceu de uma necessidade real: transformar controles manuais de reservas, clientes, brinquedos e pagamentos em uma solução digital organizada e fácil de utilizar.

O sistema centraliza toda a operação em um único ambiente, permitindo acompanhar desde uma nova reserva até os resultados financeiros do negócio.

---

## 🎠 O que o sistema faz?

### 📅 Reservas
Criação, edição e acompanhamento das locações.

### 👨‍👩‍👧 Clientes
Cadastro e gerenciamento das informações dos clientes.

### 🧸 Brinquedos
Controle dos brinquedos disponíveis para locação e manutenção.

### 🗓️ Agenda
Calendário mensal para visualizar as reservas e eventos.

### 💰 Financeiro
Controle de valores recebidos, sinal e pagamentos pendentes.

### 📊 Dashboard
Indicadores para acompanhar reservas e resultados do negócio.

## 💡 De uma necessidade real para uma solução digital

O projeto foi desenvolvido pensando em um problema real de negócio.

Antes, informações como reservas, datas, clientes, valores e disponibilidade dos brinquedos precisavam ser acompanhadas separadamente.

Com o **JuKids**, essas informações passaram a fazer parte de um único sistema.

O desenvolvimento envolveu não apenas programação, mas também:

🎯 Levantamento de necessidades  
🧩 Análise de processos  
📊 Organização de dados  
⚙️ Automação de tarefas  
🎨 Experiência do usuário  
💡 Resolução de problemas  

---

## 🤖 Recursos inteligentes

O sistema também auxilia na identificação de conflitos de agenda.

Quando um brinquedo já possui uma reserva para determinado período, o sistema verifica a disponibilidade antes da criação de uma nova locação e pode apresentar alternativas disponíveis.

Isso ajuda a evitar **reservas duplicadas e conflitos operacionais**.
